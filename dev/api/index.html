EcologicalCellularAutomata — Module
EcologicalCellularAutomata

A model zoo of published ecological cellular automata, from plant diseases and agricultural and forest pests to coastal dunes, each runnable on any compatible CellularAutomataCore.jl backend.

Each model reimplements a published cellular automaton for a plant disease, a vector of plant disease, an agricultural or forest pest, or a landform shaped by vegetation (bio-geomorphology), as a backend-agnostic CellularAutomataCore model, together with metadata recording the citation, the mechanism, the validation reported by the source, and how faithfully the reimplementation follows it. The literature these models come from is reviewed in (Tonnang et al., 2017) among others.

Part of the ecorecipes cellular-automata ecosystem.

source

The registry

Every model has a builder, which returns a backend-agnostic CAModel, a problem constructor with the setup of its source, and metadata in models/<id>/metadata.toml, read and checked when the package is compiled.

EcologicalCellularAutomata.ModelInfo — Type
ModelInfo

The metadata of a model in the zoo, from its models/<id>/metadata.toml:

  • id, title: the model's identifier and a short title.
  • category: "plant disease", "agricultural pest", "forest pest" or "bio-geomorphology"; organism and host: the pest or pathogen and what it attacks.
  • citation, doi, bibkey: the source, checked against the published paper, and its key in the package bibliography.
  • ca_role: what the cellular automaton represents in the source.
  • fidelity: :reproduction (the source's model, with its parameters), :adaptation (the source's model with stated changes) or :inspired (built from the source's ideas, not its specification).
  • validation_in_source: what the source compared its model with.
  • reproduces: the figure or claim of the source that the model's vignette reproduces.
  • deviations: every way the implementation departs from the source, including details the source leaves unstated and how they were filled.
  • schemes: the update schemes the model is meant to run with.
  • source_code: the authors' code, if published, and its licence.
  • notes: anything else.

EcologicalCellularAutomata.list_models — Function
list_models(; category=nothing, fidelity=nothing) -> Vector{Symbol}

The ids of the models in the zoo, sorted, optionally only those of one category ("plant disease", "agricultural pest", "forest pest", "bio-geomorphology") or one fidelity (:reproduction, :adaptation, :inspired).

EcologicalCellularAutomata.model_info — Function
model_info(id) -> ModelInfo

The metadata of the model id (a Symbol or a string). An unknown id raises UnknownModelError.

source
EcologicalCellularAutomata.build — Function
build(id; kwargs...) -> CAModel

The CellularAutomataCore model id, with structural options given as keywords (documented by each model's builder). The model is backend-agnostic: solve a problem built from it with any scheme and backend it supports. Its parameters take the source's values by default and are changed through the problem's pmap.

source
EcologicalCellularAutomata.problem — Function
problem(id; kwargs...) -> CAProblem

A problem for the model id with the setup of its source: the lattice, the initial state and the run length, which keywords change (documented by each model's problem constructor). Every model's problem accepts seed and pmap (parameter values by name).

source

Each model's own functions are listed by category: plant diseases, agricultural pests, forest pests and bio-geomorphology.

Exceptions

Every exception the package defines subtypes the abstract root EcologicalCellularAutomataError. Invalid arguments and keywords raise Base's ArgumentError, which is outside it.

EcologicalCellularAutomata.EcologicalCellularAutomataError — Type
EcologicalCellularAutomataError

Abstract supertype of every exception that EcologicalCellularAutomata defines. It marks the package that introduced an error, not a kind of failure. Invalid arguments and keywords raise Base's ArgumentError instead, which is outside this root.

source
EcologicalCellularAutomata.UnknownModelError — Type
UnknownModelError(id, known)

Raised when a model id is not in the zoo; known lists the ids that are.

source
EcologicalCellularAutomata.MetadataError — Type
MetadataError(id, message)

Raised, when the package is compiled, if the metadata file of the model id is missing, lacks a required field, or has a field with an invalid value.
